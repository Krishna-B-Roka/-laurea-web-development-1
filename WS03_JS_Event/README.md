# Workshop 3: JavaScript Events and DOM Manipulation

This repository contains solutions for Workshop 3 exercises covering JavaScript event handling, DOM manipulation, form validation, keyboard events, and browser APIs.

## Learning Objectives

- Handle user interactions with JavaScript
- Use event listeners
- Manipulate DOM elements dynamically
- Work with form input and validation
- Capture keyboard events
- Use the Geolocation API
- Open locations in Google Maps using coordinates



## Exercises

### Exercise 1: Basic Click Events

- Display an alert when the "Click me" button is pressed.
- Show an animal table when the "Show Animal Table" button is clicked.

### Exercise 2: Event Listeners and DOM Manipulation

- Add a mouseover event to a heading.
- Print a message to the browser console.
- Dynamically change heading text and color using `addEventListener()`.

### Exercise 3: Input Events

- Detect textarea focus and blur events.
- Display status messages.
- Update a live character counter.
- Show a real-time preview of user input.

### Exercise 4: Form Submission

- Handle form submission using JavaScript.
- Prevent page reload with `event.preventDefault()`.
- Validate feedback length (10–200 characters).
- Display error and success messages.
- Reset the form after successful submission.

### Exercise 5: Keyboard Events

- Detect key presses with `keydown`.
- Display:
  - Pressed key (`event.key`)
  - Key code (`event.code`)
- Show the pressed key in large text.
- Bonus features:
  - Background color changes
  - Key press counter
  - Shift/Ctrl/Alt key detection
