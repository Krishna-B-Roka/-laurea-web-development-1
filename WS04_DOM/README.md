# Workshop 3: JavaScript Events and DOM Manipulation

## Learning Objectives

By completing this workshop, I learned how to:

- Use JavaScript to select and manipulate HTML elements.
- Add event listeners to buttons, forms, images, and dropdown menus.
- Modify text, styles, and attributes dynamically.
- Create and append new HTML elements using JavaScript.
- Handle form submissions and validate user input.
- Use CSS classes to create visual effects and animations.
- Work with DOM methods such as `querySelector()`, `querySelectorAll()`, `createElement()`, `append()`, and `remove()`.

## Exercises

### Task 1: Changing Content
- Added event listeners to buttons.
- Changed heading text dynamically.
- Used `classList.toggle()` to add and remove CSS classes.
- Updated animal descriptions using `textContent`.

### Task 2: Creating Elements with JavaScript
- Created headings, paragraphs, and images dynamically.
- Appended elements to the page using `append()`.
- Added CSS classes to created elements.
- Implemented hide and show functionality for content.

### Task 3: Selecting an Animal
- Used a dropdown menu to select different animals.
- Updated animal names, descriptions, images, and alt text based on the selection.
- Added image hover effects using `mouseenter` and `mouseleave` events.

### Task 4: Adding Animal Observations
- Handled form submissions with the `submit` event.
- Prevented page refresh using `event.preventDefault()`.
- Validated form input fields.
- Created and added new table rows dynamically.
- Implemented row removal functionality as a bonus feature.
